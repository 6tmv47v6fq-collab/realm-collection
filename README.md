# REALM — LaunchMyNFT upload

The 1,111 beings in the launchpad's format: files numbered from 0, an image
and a JSON for each, plus `collection.png` / `collection.json`.

Token N in the main branch is file N-1 here (REALM #1 = 0.png, REALM #1111 =
1110.png). The images are byte-for-byte the originals, so the provenance hash
is unchanged: 97ad789cab86faf23c77028ae113d52d814043255d606ec79b0d69a20feee5c6

Download: Code → Download ZIP, unzip, upload the `assets` folder.
